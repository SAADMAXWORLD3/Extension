
# UnityAdsExtension

An extension for Kodular that integrates Unity Ads into your Android applications.

## 📦 Features
- Display Unity Ads with a simple block
- Lightweight and easy to integrate
- Designed for Kodular and App Inventor platforms

## 🛠️ Installation
1. Download the `.aix` file from the [Releases](https://github.com/yourusername/UnityAdsExtension/releases) or use the hosted link.
2. Open your project in [Kodular Creator](https://creator.kodular.io).
3. Go to **Extensions** → **Import Extension** → **URL**.
4. Paste the hosted link to your `.aix` file and click **Import**.

## 🚀 Usage
Once imported, drag the `UnityAdsExtension` component into your app and use the `ShowAd` block to display Unity Ads.
